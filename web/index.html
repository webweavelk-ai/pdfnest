Why this is different

Most free PDF sites upload your file to a server, process it there and delete it later. That means waiting for an upload, trusting a stranger with a contract or a payslip, and hoping the deletion promise is true. Here the file never leaves the tab it was opened in. You can load the page, go offline, and everything still works.

It is also why these tools are free with no daily quota: there is no server to pay for. No GPU, no cloud bills, and no ad-funded limit on how many documents you may process.

Questions

Is it really free, with no catch?

Yes. There is no server and therefore no running cost to cover, so there are no daily limits, no watermarks and no forced signup. Everything runs on the machine you are already using.

Are my documents private?

They never leave your device. There is no upload step at all — you can open your browser's network tab and watch that nothing is sent while a file is processed.

Does it work offline?

Once the page has loaded, yes. The processing libraries are served from this site itself rather than a third-party CDN, so no external request is needed during processing.

What is the file size limit?

Your device's memory. Documents up to roughly 150 MB are comfortable on a typical laptop; very large files need a bigger machine rather than a paid plan.

Do I need to install anything?

No. Everything runs in the browser, so there is no app, no extension and no plugin to install.
